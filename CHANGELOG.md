# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-31

### Added
- Five theme variants: Norte, Norte Bright, Norte Italic, Norte Bright Italic and Norte Light, each with a UI theme and an editor color scheme.
- Islands UI support (IntelliJ Platform 2025.3+), extending `Islands Dark` / `Islands Light`.
- Syntax colors for the platform defaults and for JavaScript, TypeScript, JSON, Python, CSS, HTML, XML, Markdown, YAML and regular expressions.
- Console and log colors, search and brace highlighting, VCS file status colors.
- Zero-dependency converter that generates the themes from VS Code theme files, with unit, determinism and snapshot tests.
- Plugin icon.
